# v0.1.0 — Initial public portfolio release

This release presents the completed vLLM inference control-plane lab as a bounded engineering
portfolio project.

Highlights:

- Canonical OpenAI-compatible streaming inference gateway
- Multi-replica round-robin and outstanding-work-aware routing
- Bounded admission, queueing, and overload protection
- Replay-safe failover before client-visible content
- Health, exclusion, recovery, and slow-replica lifecycle handling
- CPU-only demo using deterministic fake replicas
- Controlled E5–E11 GPU experiments with reviewed results and explicit claim boundaries

This is an experimental research system, not a production-ready serving platform. Results are
specific to the recorded hardware, model, workload, and protocols described in the repository.
