# Evidence index

This directory is the compact evidence surface for the portfolio repository.

- [`summaries/`](summaries) retains the final reports, independent audits, and provenance records
  needed to support claims made in the project README.
- [`charts/`](charts) retains four presentation-quality figures from the single-replica study.

This public repository intentionally excludes large raw request streams, server logs, repeated
deployment snapshots, temporary packages, and provider-specific retention inventories. Those
materials are preserved separately. The retained summaries record the measured results, protocol
boundaries, corrections, and limitations needed to evaluate the public claims.

Provider-specific volume identifiers, container hostnames, GPU UUIDs, PCI addresses, and temporary
worktree paths are generalized in this public export; hardware class and topology remain intact.
